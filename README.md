# Доска задач с Gemini

Учебный проект на JavaScript: три колонки задач, ручное управление и команды на русском через Gemini API.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
cp .env.example .env
```

В `.env` укажи свой `GEMINI_API_KEY`. При необходимости измени `GEMINI_MODEL` на доступную твоему ключу модель.

```bash
npm start
```

Открой http://127.0.0.1:3001.

## Как работает

Браузер отправляет команду и текущие задачи в `POST /api/chat`. Сервер добавляет системный промпт и описания функций из `tools.js`, затем делает один запрос к Gemini API. Модель выбирает функции, а браузер выполняет их и обновляет карточки.

Доступны `list_cards`, `add_card`, `update_card`, `delete_card`. Перемещение задачи — изменение статуса через `update_card`.

- `server.js` — сервер Express, системный промпт и запрос к Gemini.
- `public/index.html` — разметка и стили.
- `public/app.js` — задачи, отрисовка и выполнение функций.
- `tools.js` — описания функций для модели; сервер передаёт их Gemini.

Это версия с Function Calling. Внешний MCP-клиент не требуется. Задачи хранятся в памяти браузера и сбрасываются после перезагрузки страницы. Ключ остаётся на сервере; `.env` не загружается в Git.
